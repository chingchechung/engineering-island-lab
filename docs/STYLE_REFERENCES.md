# 使用者提供的島嶼美術參考（僅供視覺研究）

此資料夾中的圖是教師在需求討論時上傳的視覺參考，**不應被直接作為正式網站上的 2D/3D 素材；不得假定具有可再散布的原作者授權**。只供 Codex / 設計者理解希望的造型，不要把圖檔放進部署的 `dist/`。

1. `style-references/00-avoid-regular-cube-islands.png`：**反例**，島嶼構圖及斜上方視角可參考，但太過規則的立方柱／六角柱岩體外形不接受。
2. `style-references/01-tiered-waterfall-island.png`：多層地貌、瀑布、環形道路、自然厚度與立體感，可用於中央主島及森林島。
3. `style-references/02-organic-rock-island.png`：不規則的自然岩島剪影，作為一般單元島主要的地形參考。不要變成單一幾何柱體。
4. `style-references/03-fantasy-floating-island.png`：夢幻城堡/浮空島氛圍，僅適度用於中央學院和少數特殊島，不能把 15 座島全部做成同一款城堡。

共同偏好：明亮、色彩豐富、童話式、低多邊形但細節精緻；斜上方正交視角，放大全島後 Lecture 小屋和 NPC 可點擊，動物可清楚欣賞。
