# Engineering Island Lab — 產品與互動規格 v0.1

> 這是使用者已討論確定的產品方向。建議/參考數值僅供原型使用，必須經教師 Chrome/Edge 目視與操作驗收才能固定。

## 1. 產品目標

將遠距課程的 Sxx 週單元放在 3D 微型奇幻島嶼上：全域可以看中央學院與所有已規劃單元島，放大後直接點擊 Lecture 建築看該週 YouTube 清單；在 `quiz` 模式，點擊每題專屬 NPC 看題目影片、選答案、答對後看解答影片，全部通過後開 Google Form。島上有可愛、幽默、不合常理的自主動物動畫。這是一個靜態互動課程地圖，**不是 RPG、LMS 或安全考試平台**。

## 2. 課程與顯示規則

- `courseTitle` 自訂，例如「數位電子學」。中央學院主島以清楚的可讀中文字/英文標牌顯示該字串。
- `totalUnits` 為 1–15 的整數；**數位電子學預設 12**。僅顯示 S01 到 S`totalUnits`；S13–S15 在預設 12 的課程**完全不顯示**。
- `assignmentMode` 為 `quiz` 或 `video-only`；控制整門課的題目功能，**非根據是否有題庫檔自行猜測模式**。
- 每週教師以 `assignments/manifest.json` 統一公開可進入單元；清單以外的單元仍在縮小的世界中**可見但鎖定**，不載入影片/題庫，也不允許進入互動詳情。不得把「已公開」與「個人已完成」混淆。
- 不記錄學生姓名、帳號、播放時長、答案紀錄或任何持久化的個別完成狀態。當前頁面內可保留各島暫時答題進度，重新載入後清除。

### 預設 `public/course-config.json`

```json
{
  "courseTitle": "數位電子學",
  "totalUnits": 12,
  "assignmentMode": "quiz"
}
```

## 3. 視角與互動

- 整個群島屬於**同一個連續 3D 世界／同一套相機操控**，不以每島重新開一個頁面或突兀切場代替縮放。
- 初始為斜上方約 40°–50° 的 `OrthographicCamera`，優先保持微型模型/isometric-like 視覺；相機角度可設有限旋轉，不能失去全域導航能力。
- 滑鼠滾輪：平滑縮放；拖曳海面/空白：平移；單擊可用島：平滑移動並聚焦；全域總覽按鈕：一鍵縮回整個群島；聚焦島嶼仍可再縮放欣賞細節。
- 需要以移動距離閾值區分 click vs drag，防止拖地圖時錯誤觸發 NPC 或 Lecture；若 Modal 開啟，滾輪與鍵盤事件只操作 Modal，不意外操作場景。
- 縮小時：所有 `totalUnits` 島、中央島與開放/鎖定狀態可讀；各島主輪廓/主題明顯，NPC 小字不必強制顯示。放大時：Lecture 小屋、NPC 頭頂 Qxx、動物與場景細節清楚可見。
- 島上不放學生代表人物；無 WASD、碰撞移動、跳躍、人物尋路。支援滑鼠點擊為主；適當預留 touch 點擊/縮放適配，但優先驗收 Windows Chrome/Edge。
- 相機的整體 bounding box 要依 `totalUnits` 自動適配，1–15 都不能發生漏島或視角裁切。

## 4. 世界布局與主島

- 以中央學院主島 + 周圍非機械規則的 1–15 座單元島構成群島；位置可為固定的最多 15 個經設計的座標或可控的 deterministic 佈局，不必為了演算法而過度複雜。避免重疊和點擊遮擋，保持全域能辨識 Sxx。
- 中央主島是視覺焦點，較大並有學院建築、可讀的 `courseTitle` 招牌、總單元數/目前已發布資訊，可有小瀑布、花園、燈塔或校園廣場；主島不負責題目作答。
- 任一時刻都能回全域總覽。鎖定島可供觀看外觀與名字，但點擊不進入教學互動，顯示『尚未開放』；未開放島不要當作不存在。

## 5. 地貌與色彩規則

- **微型奇幻地貌 / colorful whimsical stylized 3D diorama**：色彩明亮豐富，但場景有主次層次、足夠對比讓文字與 NPC 讀得清楚。
- 參考三類造型：瀑布+環繞步道的多層島、自然單體岩島+盤旋坡道、特殊的童話浮空城堡島。主島以第一/第三類融合，一般單元以第二類為主，少數幻想島使用第三類。**不直接複製任何來源的受版權保護模型**。
- 島輪廓要不規則、有海角、內凹與高低差；上面有草地/沙地/冰雪、邊緣有漸變土層或海蝕岩壁；側面不要是垂直直落的規則方柱/六角柱。島體有厚度、自然岩坡及視覺重量；可依主題有部分浮空島。
- 不要讓 12 座島只是換個顏色的同一個平盤；每島都需要一個獨特的地貌剪影，且近看仍有裝飾細節。
- 同一套共用場景工廠/素材元件，依固定每島 preset 生成地貌、植被、小屋外形、動物；**不設可編輯 `islands.json`**，因教師不需要學期中編修地貌。

## 6. 動物與環境動畫

- 小動物（約 4–8 隻/聚焦島的原型量）純環境裝飾，**玩家無法點擊互動、餵食、追趕、推動、操控、改變行為**。不參與 Quiz、不阻礙 NPC，也不遮住文字標籤或滑鼠點擊區。
- 不要求真實生物常理，例如 S01 鯊魚在陸地跳躍；具備簡單自主循環（idle、hop、turn、float、flap、wander），不必 AI 尋路或物理引擎。動畫相位需錯開，不讓所有動物同步。
- 可加海面緩慢變化、岸邊浪花、樹葉擺動、花草、雲與小瀑布。優先確保一般筆電能流暢；遠景動物可降頻、隱藏或採用廉價版本，避免一次同時渲染所有 15 島的昂貴動畫。

## 7. Lecture 小屋與影片清單（兩模式共同）

- 每個**已開放**單元島都有一座清楚可見、可直接點擊的 Lecture 小屋（外觀依主題變化），有播放 icon 或 `Lecture Videos` 招牌。
- 點擊小屋開啟浮動 Modal；固定標題和關閉按鈕，中間清單區**垂直捲動**。影片個數完全不固定；不區分中文/英文、不自動排序、不插入影片、不做頁籤。
- 清單是 `course-videos/Sxx.json` 中 `videos[]` 的**原始排列順序**，每項顯示 `title`，提供『在 YouTube 觀看』按鈕。點擊後**另開新分頁**，原本 Modal 保持開啟，不嵌入播放器、不自動播、不追蹤看過沒有。
- 關閉按鈕與 Esc 關閉 Modal；滑鼠滾輪只捲 Modal，不帶動 3D 場景。清單很長仍不超出視窗，至少應能在一般 1366x768 螢幕及較窄視窗中讀取。若此單元影片資料缺失或無效，要清楚回報，不能顯示虛構連結。

## 8. Quiz 模式專屬 NPC 與作業流程

- 僅 `assignmentMode: "quiz"`：已開放島的題庫 `questions` 有 4 或 5 題，依每題產生**一個 NPC**。Q01～Q04 必有，只有五題才顯示 Q05。NPC 分散在島不同位置，但不要互相遮擋；不需走近即可點擊。
- NPC 色彩/裝扮鮮明、體型足夠大；**頭頂浮動 Q01/Q02... 標牌 + 衣服/帽子顯著 Qxx 識別**。hover 強調可點擊目標；答對顯示 Qxx ✓（例如綠色標記），仍能打開題目回顧。
- 點擊後開 Modal，顯示 `questionVideoUrl`、選項、答案回饋；答錯可重試，答對後才顯示 `explanationVideoUrl` 與選用的解說文字。原有 v1/v2 意義不改：v1 單一 `correctOption`；v2 `correctOptions` 陣列，學生**仍只選一個**，只要選中的選項屬於陣列即算正確。不可擅自當多選題。
- **同一單元全部 4/4 或 5/5 通過**才顯示 Google Forms 外連；Form 由 Google 管理。題目與解答的 YouTube 一律由學生點擊另開分頁。
- `assignmentMode: "video-only"`：**不生成任何題目 NPC、不顯示 Q01～Q05 標牌、不顯示題目 Modal、題目進度、解答及 Google Forms**，同一套地形、Lecture 小屋與動物仍正常。
- 開放島在 Quiz 模式缺題庫/題庫損毀時必須顯示『作業內容載入失敗』而不是默默切換成 video-only，也不能依缺檔判定關閉作業模式。
- 公開的題目 JSON 含答案，不能假裝具備防作弊能力；平台是練習用途，非安全考試系統。

## 9. UX 與效能驗收方向

- 初始縮小總覽能看清中央學院與課程需要的全部島，包括有鎖頭的未開放島；單元島放大後能清楚點到小屋/NPC，NPC 標籤在一般螢幕可讀。
- 滑鼠操作順暢；點小屋/NPC/島不誤觸拖曳，動畫運作但不干涉操作。鎖定島不開啟課程內容。
- 色彩豐富但不刺眼；不要只拼幾何體做出粗糙工程測試頁後宣稱完成美術驗收。第一階段可先粗模，但必須清楚標示待美術精修。
- 避免巨型模型依賴、隨機大資產、重度陰影或高成本後製；若模型/材質取自第三方，需列明來源和授權，不使用不確定可商用/再散布的素材。
